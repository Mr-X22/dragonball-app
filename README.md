Dragon Ball Characters App
Aplicación web que consume la [API de Dragon Ball](https://web.dragonball-api.com/documentation) para mostrar personajes de la serie con sus atributos principales: **Imagen, Nombre, KI y Descripción**.  
El proyecto se desarrolló en **HTML, CSS y JavaScript nativo**, con un enfoque en diseño claro, funcionalidad y documentación profesional.


Funcionalidad
- Pantalla principal con tarjetas de personajes.
- Paginación de **10 personajes por página** (5 arriba y 5 abajo).
- Pantalla detalle con:
  - Imagen uniforme con aura.
  - Nombre grande y centrado.
  - KI resaltado en negritas.
  - Descripción con scroll.
- Botón azul para regresar al roster.
- Estilos temáticos con fondo personalizado.

Tecnologías usadas
- HTML5
- CSS3
- JavaScript (nativo)
- API pública de Dragon Ball
